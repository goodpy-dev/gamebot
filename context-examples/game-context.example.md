# (선택) 지금 만들고 있는 게임 요약

게임을 만들고 있다면 이 파일을 `data/game-context.md` 로 복사해서 채워 주세요.
있으면 "스킬창이 별로야" 같은 질문에 봇이 **내 게임의 지금 구조**를 짚고 시작합니다. 없으면 질문과 붙인 캡처만 보고 짚어요.

## 한 줄
- 예: PC 화면 아래 띠에서 기사가 알아서 싸우는 방치형 RPG.

## 루프
- 예: 원정(자동 전투) → 귀환 보고 → 캠프에서 장비·스킬 선택 → 다시 원정.

## 고민 중인 시스템 (예: 스킬)
- 예: 쓰면 자라는 숙련 + 스킬마다 끼우는 룬, 장착 순서 = 연계.
